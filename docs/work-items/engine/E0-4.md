## E0-4: Unix event time and persistent record references

This issue follows [extensions-plan.md](https://github.com/TheArctesian/anima.ing/blob/main/docs/extensions-plan.md) Sections 2.3 and 2.10 and the E0-4 task table in Section 5.1. The plan is the source of truth. If this text and the plan differ, the plan governs.

The operator ruled on 2026-11-16: this issue governs E0-4, and its rules are in the plan as TML-008 to TML-012 and LNK-005 to LNK-006. The work is on the branch `engine/e0-4-timeline-links`. It is not yet merged into `main`.

### Decided

- **Event instants (TML-008).** An event instant that Anima machines exchange or store is one count: microseconds since 1970-01-01T00:00:00Z (UTC), as a signed 64-bit integer. A text form, such as RFC 3339 in the API, gives the same count when it is read again. A time zone changes only how an instant is shown.
- **Event time and received time (TML-009).** Evidence keeps the event time of the source as its start time. The time the hub received the record is a separate value. An unknown or approximate event time gets an uncertainty note.
- **Dates (TML-010).** A calendar date, a recurring schedule and its time zone are not instants. Do not change a date to an instant at midnight.
- **Clocks (TML-011).** The timeline does not claim an exact order between entries from the clocks of different machines. Old source events are not changed to hide clock skew.
- **Replays (TML-012).** A replay of the same source record does not make a second entry. A record of the same event from a different source is a separate entry, kept with `superseded_by` (TML-005).
- **References (LNK-005).** A record reference is `kind:id`. Only the domain that owns the record reads the `id`. A reference is not the address of a row on one machine, and it does not change when the record is imported again.
- **Missing targets (LNK-006).** A link whose target does not exist keeps its target reference and its label. It does not stop the work of its source extension and does not copy the record of a different domain.
- **Kept rules.** TML-001 to TML-007 (timeline evidence, no copied data, closed category list, the event log as a source) and LNK-001 to LNK-004 (one `record_link` table, labels for missing targets, the shared component, shared subject keys).

### Open (plan Section 7)

- **OD-E16.** Clock synchronization between machines: how skew is found and reported, the permitted skew, and what an unreliable clock does. E0-4 builds no clock check.
- **OD-E17.** The portable form of a reference across machines and replicas, and what a link does when its target is deleted.
- The shared-state and replication design is not decided. This issue selects no database, ORM or coordinator.

### Acceptance criteria

- [ ] The instant unit is documented, and an instant does not change between time zones; event time and received time stay separate (TML-008, TML-009).
- [ ] A replay is idempotent; separate observations from different sources both survive with `superseded_by` (TML-005, TML-012).
- [ ] A link to a missing target keeps its reference and label and does not block its source (LNK-006).
- [ ] Dates keep their meaning (TML-010).
- [ ] Live check on a real hub (T8).
- Clock synchronization and skew detection, and identity across machines, wait for OD-E16 and OD-E17. They are not E0-4 acceptance criteria until the operator decides them.
