Operator, 2026-11-13: "Instalation is either dmg or app img that is installed".

The `anima` command line program and its MCP server (`anima mcp`) are on `main`. They are not in the desktop bundle. Today a person must build them from source.

Specification: `docs/design-spec.md` on branch `claude/spec-cli-distribution` (commit 060f87e8). It is not on `main` yet. Section 3.11.

## Requirements (not built)

- INS-001: the `.dmg` (macOS) or the AppImage (Linux) is the only installation path.
- INS-002: `anima` is inside each artefact, at the same version. One download.
- INS-003: `anima --version` equals the version of the application.
- INS-004: macOS: "Install the command line tool" makes a link in a directory on the PATH. The operator confirms it.
- INS-005: Linux: the AppImage writes a small launcher.
- INS-006: a row in Settings, Updates: state, path, "Remove".
- INS-007: an update replaces the application and `anima` together.
- INS-008: no package manager channel.
- INS-009: the Tauri shell does this work. It never handles an administrator password.

## Open decisions

- [ ] OD-16: a second program in the bundle. Signing and notarization with the Developer ID are not verified.
- [ ] OD-17: the version of `anima`. BLD-043 gives the release version only to the Tauri configuration.
- [ ] OD-18: the AppImage launcher: the link after an update, and a computer with no display.

`anima-agent` keeps its own install path (MET-019, MET-024).
