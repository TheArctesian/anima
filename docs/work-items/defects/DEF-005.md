## What was seen

His words: "when I click +VNC it tries to open tailscale why is this". He had quit Tailscale, because a hosted hub is reached through the link and has no VPN.

## Cause, from the code

Read in the code of `dev` at `3353f648`. Not run again.

- The flow of the button (`apps/client/src/lib/devices/screen-sharing/flow.ts`, `start`) first asks which computer this is: `readThisMachine` (`apps/client/src/lib/desktop/this-machine.ts`).
- `readThisMachine` asks the hub for `vpnLoginServer`. Each hub answers with the constant `https://hs.anima.ing` (`crates/hub/src/fleet/vpn.rs`), a hosted hub too. The hub does not say in which mode it is.
- With that answer the desktop command `this_machine_read` runs the Tailscale client twice, `debug prefs` and `status --json` (`apps/desktop/src-tauri/src/this_machine/vpn_client.rs`). On a Mac the first place it looks is `/Applications/Tailscale.app/Contents/MacOS/Tailscale`, which is the application itself. A question to it starts the application when it was quit.

Each caller of `readThisMachine`, and what it did on a hosted hub:

| Caller | When | On a hosted hub |
| --- | --- | --- |
| `routes/devices/+page.svelte`, `readHere` | "Add device", and the question about this computer after the sign-in (R-060) | "Add device" ran the client. The question after the sign-in did not: a hosted hub adds this computer by the link (HMD-044) |
| `lib/devices/screen-sharing/calls.ts` | "+ VNC" | Ran the client. This is what the operator saw |
| `lib/desktop/daemon/shell.ts` | Each opening of the settings of a device (the panel "Daemon") | Ran the client |
| `lib/builds/desktop.svelte.ts` | The name of this computer as a builder | Ran the client, only to read the name |

In each case the answer had no VPN address, so the client got "not this computer". Thus on a hosted hub the flow of "+ VNC" never opens System Settings > Sharing for the Mac of the person, and "Install on this computer" is never offered.

## Effect

- The application starts a program that the hub does not use, on each of the four paths.
- On a hosted hub the application does not know that a device is this computer.
