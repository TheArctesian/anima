**Found:** 2026-11-07, Pop!_OS 24.04 (COSMIC, Wayland) setup as the Linux test device; main at b33788f8 and 8b231e0c.

**What happens:** `bun run --cwd apps/desktop tauri build` fails on Linux:

```
error: this lint expectation is unfulfilled
  --> apps/desktop/src-tauri/src/web_view/event.rs:44:13  (and :55:13)
   = note: only macOS has a trust hook until OD-7 runs on Linux
   = note: `-D unfulfilled-lint-expectations` implied by `-D warnings`
```

**Cause:** `WebViewEvent::Untrusted` and `::Mismatch` carry `#[cfg_attr(not(any(target_os = "macos", test)), expect(dead_code, ...))]`, but `WebViewEvent::refusal()` (event.rs:97 and :104) builds both on every platform, so on Linux they are not dead and the expectation fails under `warnings = "deny"`.

**Workaround used:** `RUSTFLAGS=--cap-lints=warn` for the build only (no code change). The bundles (.deb, AppImage) then build and run.

**Fix direction:** drop the two `expect(dead_code)` attributes, or narrow them to where the variants really are unused. Check with a Linux `cargo clippy --all-targets -- -D warnings`.
