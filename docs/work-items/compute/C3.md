**Ownership / priority clarification (2026-11-07):**

C3 depends on C1 [C1](C1.md). This is issue #36 (single-node offload), not WP-36 Builds. Do not require offload for a vision model that fits one node. Phase 1 is already complete ([handoff](../../programme/handoff.md)); C1 remains a prerequisite.

---

Run a model larger than a node's GPU memory by moving weights (never the KV cache) to system memory. Rank choices by estimated ms per token. Add KTransformers on a large-memory node if the operator has one.

**Done when:** a model 20 % larger than the GPU memory of a node runs on that node with offload.
