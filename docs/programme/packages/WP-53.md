## Findings from planning (2026-11-11, `phase-3` 20653a6b)

- Most agent-checkable criteria already have proofs in the hub suite. Examples: criterion 4 in
  `tests/it/browser/` (`d_3_sign_in_browser_sets_exactly_the_cookie_and_answers_without_the_token`,
  `d_3_the_cookie_signs_in_only_with_the_public_origin`, `d_3_a_socket_from_another_origin_ignores_the_cookie`,
  `a_8_logout_deletes_the_browser_token_and_clears_the_cookie`, `sec_002_the_desktop_app_still_signs_in_from_its_web_view`)
  and `src/web_client/tests/headers.rs`; criterion 12 in `src/checks/exposition*` (`int_001_*`, `int_002_*`,
  `d_24_*`) and `tests/it/bearer/` (`d_24_int_001_metrics_without_a_token_answers_401_and_starts_no_build`);
  criterion 13 in `tests/it/api_keys/` (20 tests, from the shown-once secret to revoke and audit); criterion 15 in
  `tests/it/sessions/start/limit.rs` (8 `ra_036_*` tests, including files tickets and parallel starts). The matrix
  cites them and does not duplicate them.
- K1 has no `@pending` use today (only the directive declaration and its comment), and `quality/baseline.json` is
  `{}`. A gate test that failed on any `@pending` would block WP-48 and WP-49 additions during the phase, so the
  criterion 24 check is an on-demand script, not a gate test.
- LOG-007 has 59 files with `log_007` tests, each for one call site. No test drives the whole hub through every
  Phase 3 secret and scans one captured log for all of them. That is the main gap for criterion 22 (T5).
- Deployed configuration is not proved by in-process tests: the live hub's static headers, `/metrics` refusal, CORS
  for the two Tauri origins only, and the Prometheus text of the real hub. T4 gives the operator one probe for them.
- Criterion 14 (share links) is withdrawn by R-111. Criteria 16 to 18 are withdrawn by R-113 (plan working copy).
  Criterion 22 then drops "share token" and "recording key", and criterion 23 drops "on the watch page or in
  playback". Q-2 asks main to confirm these readings.

## Decisions

- **A-1** Criterion 24 is a script run at acceptance, not a gate test (see Findings).
- **A-2** Live probes read real keys only from a file path the operator gives, and print no secret. Agents run them
  only against synthetic local servers or a local hub with synthetic config.
- **A-3** The log scanner reports line and kind only, so its own output cannot leak what it finds.
- **A-4** Existing tests that prove a criterion are cited by file and test name; no duplicates are written.
