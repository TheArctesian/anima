## Decisions

- **A-1** Criterion 24 is a script run at acceptance, not a gate test (see Findings).
- **A-2** Live probes read real keys only from a file path the operator gives, and print no secret. Agents run them
  only against synthetic local servers or a local hub with synthetic config.
- **A-3** The log scanner reports line and kind only, so its own output cannot leak what it finds.
- **A-4** Existing tests that prove a criterion are cited by file and test name; no duplicates are written.
- **A-5** T7 was split by owner and kind (T7a client motion, T7b hub tests, T7c client tests, T7d docs) so each
  review has one kind.
- **A-6** Rulings from main applied here: WP-34 D-5's 100 px clause holds in Phase 3 (a jump of 100 px or more
  blocks criterion 23; under 100 px is a could for issue #1); the update banner gets an operator step (UPD-004);
  WP-53 owns the M-1 and W-1 fixes; the visible shared memory number (spec line 1010) waits for the chart header
  change in the UI redesign plan; the gate-7 hang is fixed in the tests, not by a retry in `gates.ts`.
