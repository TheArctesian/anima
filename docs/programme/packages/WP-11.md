## Decisions

- **D-1 Hub client shape (CQ-045).** `$lib/hub/` is the transport only: one `Hub` value with `request(document, variables)` (HTTP POST `/graphql`) and `subscribe(document, variables, sink)` (graphql-ws, API-002), plus the connection status. Domain clients (`$lib/devices/api.ts` and others, WP-12–WP-15) are functions that take a `Hub` (`devicesApi(hub)`), so they stay plain TypeScript and testable. Components get the `Hub` from Svelte context (`useHub()`), set once in the root layout. No component calls `fetch` (lint rule, T5).
- **D-2 Token transport (confirmed as R-020, K7 "Authentication transport").** Close code 4403 when the token is missing or not valid. HTTP: `Authorization: Bearer <token>`. WebSocket: `connection_init` payload `{ authorization: "Bearer <token>" }`; never a query parameter (LOG-007). The token comes from an injected `token: () => Promise<string | null>` (the key store is WP-16, CLI-003). The address comes from an injected value; default `https://hub.anima.ing` (NET-005). CLI-002 storage of the address is WP-15/WP-16.
- **D-3 Types (API-008).** GraphQL Code Generator `client-preset` generates typed documents from `contracts/schema.graphql` into `apps/client/src/lib/hub/generated/` (listed in `quality/generated.txt`). Documents are read only from `src/lib/*/api.ts` (CQ-045). `bun run --cwd apps/client graphql` writes; the client `lint` script fails when the output is not current (same pattern as TOK-002). R-020: WP-17 switches the source to the hub's `crates/hub/schema.graphql` when it exists.
- **D-4 Connection status (NAV-003, NET-004).** A pure reducer `nextStatus(state, signal, now)` with states `connecting`, `connected`, `unreachable`; signals come from the socket (opened, closed, error) and from requests (ok, network failure). An HTTP error with a GraphQL body (for example `UNAUTHENTICATED`) still means "on the network". `lastContactAt` gives the data age; `dataAge(since, now)` formats it. The nav shows "Connected" / "Disconnected"; when unreachable, a banner shows "Not on the network", the hub address, "Check the VPN client" and the age of the data.
- **D-5 Motion (MOT-020, OD-8).** `motion` (vanilla `animate`) is the only spring engine, imported only in `$lib/motion/` (lint rule, T5). Springs take `stiffness`/`damping`/`mass` from `tokens.ts`; release velocity is a parameter (MOT-031). Reduced motion (MOT-040/041) is read once from `matchMedia('(prefers-reduced-motion: reduce)')`, kept current with its `change` event, and passed to every helper: springs become instant, durations and stagger come from `reducedMotion`, thresholds never change (MOT-021). Interruption (MOT-002): every helper starts from the current rendered value and never awaits a timer (MOT-042).
- **D-6 Pages.** `/` redirects to `/devices` (NAV-004). `routes/devices/+page.svelte` and `routes/settings/+page.svelte` are title-only placeholders that WP-12 and WP-15 replace (they own those paths); the placeholders are the only lines WP-11 writes there.
- **D-7 Navigation folder.** The nav bar and status live in `$lib/nav/` (operator noun; no other package owns it). The route layout only composes it (CQ-044).
- **D-8 Icons (UI-014–016).** `$lib/icons/icons.ts` is the one table of Nerd Font class names to code points, checked against the bundled Propo font's character map. `Icon.svelte` renders a glyph with `aria-hidden="true"`; an icon-only button needs a label (UI-015).
