## Decisions

- **D-1 Token build location.** A new bun workspace `design/` (`@anima/design`): token source in `design/tokens/*.tokens.json` (W3C DTCG), build code in `design/src/` (not `build/`: `.gitignore` ignores every `build/` folder). Its `lint` script runs the TOK-002 "generated files current" check, so the check runs inside gate 5 (`bun run lint`) without changing the twelve-gate list. Its `test` and `check` scripts join gates 6 and 7. Needs one line in root `package.json` (`"workspaces": [..., "design"]`) — handoff H-1.
- **D-2 Build tool.** Style Dictionary 5.7.1 (spec 5.5.1 says "version 4 or later"; 5.8.0 is less than a day old, so pinned one back). Style Dictionary parses DTCG and resolves references; Anima formats (CSS, TypeScript, Rust, Markdown) are custom formats in `design/src/`.
- **D-3 Commands.** `bun run --cwd design tokens` writes all outputs. `bun run --cwd design tokens:check` builds in memory and fails, naming each stale file, if any output differs (TOK-002).
- **D-4 Springs.** Source holds `dampingRatio` and `responseS` only. The build computes `stiffness = (2π/response)²`, `damping = 4π·ζ/response`, mass 1, and emits both forms in TypeScript (K5 shape). CSS gets `--spring-<name>` as a transition fragment `<settle duration> linear(<sampled curve>)`, so CSS-only motion can still follow a spring (MOT-003); the curve comes from the closed-form damped-spring step response.
- **D-5 Reduced motion.** CSS `@media (prefers-reduced-motion: reduce)`: `--duration-press: 0ms`, `--stagger-list: 0ms`, each `--spring-*: 0ms linear` (instant move, MOT-040); `fast`, `base`, `highlight` keep their values because reduced forms are fades (5.7.3). `threshold-*` never change (MOT-021). TypeScript exports the same reduced values as `reducedMotion = { duration, stagger }` plus the rule that springs become instant; `lib/motion/` (WP-11) applies it (MOT-041).
- **D-6 Reduced transparency / contrast.** `@media (prefers-reduced-transparency: reduce)` makes each `--material-*-bg` solid and `-blur: 0px`, `-saturate: 100%` (5.6). `prefers-contrast: more` (MAT-006) also emitted: solid materials, `--border` = `text-muted`.
- **D-7 Tints (5.5.3).** "The colour at 12 % on `surface`": emitted as `color-mix(in srgb, <colour> 12%, var(--surface))` — stays correct when a theme changes `surface` (TOK-011).
- **D-8 Themes (UI-005, TOK-011).** Semantic colours reference primitives by DTCG alias; the CSS uses `var(--nord-N)` for semantic tokens so a later light theme only redefines semantic tokens.
- **D-9 Fonts.** Five files from `ryanoasis/nerd-fonts` at `f034eeafc0ccf79afa8dd952feb86b18e5d0469e` (UI-022): Propo Regular/Bold/Italic/BoldItalic `.otf`, Mono Regular `.otf`, plus the Symbols Nerd Font fallback (`font-icon` fallback, 5.2 table). Stored in `apps/client/src/styles/fonts/` with `OFL.txt` / `LICENSE` and a `fonts.lock.json` (path, URL, SHA-256). `@font-face` rules in `apps/client/src/styles/fonts.css` with relative `url()` so Vite bundles them (UI-017). `apps/client/src/styles/global.css` imports `tokens.css` and `fonts.css` — the one file WP-11 imports.
- **D-10 Terminal palette (RA-010).** ANSI mapping lives in the token source (`terminal.tokens.json`, aliases into Nord, the standard Nord terminal mapping) so `crates/theme/src/generated.rs` holds `NORD` and the terminal palette; `crates/theme/src/lib.rs` (hand-written) holds `Rgb` and `guac_color_scheme()`, output in guacd's `color-scheme` syntax (`background: rgb:RR/GG/BB;foreground: …;color0: …`).
- **D-11 Breakpoints** are TypeScript only (K5); exported as `breakpoint = { compact, medium, wide }` with pixel bounds.

### Test plan

- T1: spring conversion against the formulas (stiffness, damping, mass 1) for all four springs; `tokens:check` passes on a fresh build and fails with the file name after one byte of an output changes; every K5 name exists in CSS (except breakpoints) and in TS where K5 says; reduced-motion block changes no `threshold-*`; semantic colours resolve to the 5.1 hex values; `rem` units for sizes and space (TOK-020).
- T2: each `@font-face` `src` resolves to a committed file whose SHA-256 matches `fonts.lock.json`; no `http` URL in styles; client build output contains the font files.
- T3: `NORD[8] == #88C0D0`; `guac_color_scheme()` has background, foreground and `color0`–`color15` in guacd syntax, exact expected string.
- T4: Stylelint refuses `--f: Fira Code`, `--e: linear`, `--z: calc(1 + 2)`, and primitive `var(--nord-N)` in component code (TOK-010); ESLint refuses hex colour, `cubic-bezier(` string and numeric `duration`/`stiffness`/`damping` literals in `apps/client` TS/Svelte outside generated `tokens.ts`.
