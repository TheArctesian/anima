## Decisions

- **D-1 Proxy in TypeScript on Bun, not nginx.** The allow list is a pure function (method, path, query →
  allow or refuse) with unit tests in the gates; the edge forwards to the unix socket with Bun's `fetch`
  `unix` option. nginx would need a binary in the gates to test its config.
- **D-2 The proxy has its own internal network `localapi`, not `gateway`.** The plan says "on the
  `gateway` network". guacd is on `gateway` and has no authentication (GW-003); on its own internal
  network only the hub can reach the proxy, and the proxy has no route out. Its subnet joins
  `ANIMA_PROBE_DENY` (P2-004, D-7).
- **D-3 Socket by directory mount.** `/var/run/tailscale` is mounted read-only at `/run/tailscale`, so a
  restart of `tailscaled` (new socket inode) does not leave a stale bind. No SELinux label: the
  directory is the host's, and SELinux is disabled on the VPS (R-054).
- **D-4 Narrow ping.** `POST /localapi/v0/ping` only with `ip` in 100.64.0.0/10 and `type=disco`;
  `GET /localapi/v0/status` with no query or `peers=true|false`. Everything else is refused with 403 and
  never reaches `tailscaled`.
- **D-5 VNC grant for the Mac now; RDP grant when the Windows machine exists.** Criterion 3 needs
  tcp:5900 on `device-stephens-mac`. No Windows device has a name or address yet, so its grant is a
  live step template, not a policy row (R-061: tests name only existing identities).
- **D-6 Drive volume seeded by the image.** The image creates `/var/lib/guacd/drives` owned by guacd
  (1000), mode 0700, so a new named volume copies that owner. Root stays read-only.
