## Decisions

- **P-1 Retention is read once per daily run.** `upkeep.rs` runs one daily job, `retention`. It reads
  `retention::periods` and passes each period to its domain's job: checks `drop_expired`, events
  `keep_partitions`, metrics `keep_partitions`. Recordings and deliveries are passed by the WP-48 and
  WP-45 jobs once those exist (handoff note). A read failure skips that run and logs it; nothing falls
  back to a default.
- **P-2 The checks daily job leaves the scheduler.** `scheduler/daily.rs` and the scheduler's
  `next_daily` state go away. `checks::drop_expired(db, now, heartbeats_keep)` creates partitions ahead,
  drops expired ones, trims the aggregates (fixed, DB-009) and sweeps orphans. It is wiring only (K3).
- **P-3 Floors (CR-6).** Migration 0320 sets the checks heartbeat floor to 1 day, 0504 sets the event_log
  floor to 30 days (audit stays 1 year), and 0702 sets the metrics samples floor to 1 day.
- **P-4 Check defaults.** Migration 0321 adds `checks.defaults`. `add_default_check` reads it in the
  caller's transaction. `createCheck` keeps the K1 input defaults (D-26).
- **P-5 Exposition load bound.** One build of the whole exposition takes a fixed number of queries,
  whatever the check count. The result is cached for 10 s, and concurrent scrapes during a rebuild
  share one build (single flight). Label values pass through `text::clean` (WP-41 T3) and the format's
  escaping.
- **P-6 RDAP egress.** Every RDAP and IANA bootstrap connection goes through `targets::resolve_checked`
  (P3-003). It uses HTTPS only, verifies TLS, allows at most 3 redirects with each hop checked again as a
  new target, and caps the body size. The bootstrap is cached 24 h.
