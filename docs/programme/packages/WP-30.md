## Decisions

- **D-1 Suggestions read `checks::for_devices` until `checks::http_urls` exists.** K3 names
  `checks::http_urls` (WP-29, not started). The domain reads the HTTP checks through the existing face
  `checks::for_devices` and keeps `(CheckId, url)` only, in one private function, so the swap to
  `http_urls` is one call. Handoff H-1 to WP-29. The domain edge `web_interfaces → checks` is in K3.
- **D-2 `Device.webInterfaces` and `Device.webInterfaceSuggestions` stay `@pending`.** They are fields of
  `Device` in `devices/graphql.rs` (WP-21, R-011 composition). This package serves the faces and the
  GraphQL object types; H-2 gives the devices owner the resolvers.
- **D-3 Audit target `Device`.** `events::AuditTarget` has no web interface kind and `events/` is not
  ours. Each mutation writes one audit entry on `AuditTarget::Device(device)`; `change` names the
  interface id and the changed fields (LOG-005). A certificate accept uses action `accept` with the
  fingerprint and URL origin (WEB-009). Could: a `WebInterface` audit target (H-3).
- **D-4 URL rule (WEB-001).** `http` or `https`, a host, no user name or password (LOG-007), no
  fragment, at most 2048 bytes, trimmed. Stored as the operator typed it (trimmed), so the form's
  `webChanged` stays true to the saved text. Suggestion matching compares parsed (canonical) URLs.
- **D-5 Fingerprint form (WEB-008).** Input: 64 hex digits, colons between byte pairs allowed, any case.
  Stored and returned as 64 lower-case hex digits. Only an `https` interface takes a pin. Accept
  replaces an earlier pin (the operator accepted the new one after the client's warning).
- **D-6 A URL change to another origin drops the pin.** An update that changes scheme, host or port
  deletes the pin in the same transaction; a path change keeps it.
- **D-7 A suggestion shows** for each HTTP check of the device whose id is not in `dismissed` and whose
  URL is not already an interface of that device. Label: the URL host. Accept creates the interface
  (`ANIMA_TAB`), dismiss inserts into `dismissed`; both are idempotent for the same check.
