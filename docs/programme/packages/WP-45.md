## Decisions

- **N-1 One egress path (P3-003, D-17).** Every notification connection is built in `notifications/egress/`.
  HTTP: `targets::resolve_checked` once, then a reqwest client pinned to those addresses for that one host
  (`resolve_to_addrs`), with a DNS resolver that refuses every name, so no second lookup can happen; no
  redirect (`Policy::none()`, a 3xx is a failed delivery); no proxy; no cookies; no decompression; TLS always
  verified with the built-in roots; 8 s limit; at most 4 KiB of the reply read and discarded. SMTP: lettre
  connects to a checked IP literal, with `TlsParameters` naming the host, so SNI and certificate verification
  use the host name; implicit TLS (465) or STARTTLS required (587); no plaintext login.
- **N-2 Proof first.** T1 lands the egress path with tests that prove N-1 before any channel code exists (plan
  package note).
- **N-3 Plain HTTP stays allowed for targets on the operator's network.** D-17 forbids skipping TLS
  verification, not `http://`: the compose Apprise service is `http://apprise:8000` on `notify`, and a LAN
  ntfy may be plain HTTP. A secret-bearing `http://` URL to a public address is a should for review to judge,
  not a T1 rule.
- **N-4 Apprise query keys (WP-52 handoff).** A stateless Apprise URL whose query has a key outside a fixed
  allow list is a VALIDATION error at save, and is refused again before sending. `template`, and any key that
  makes Apprise fetch or read something, is not on the list. The firewall contains it today; the hub does not
  rely on that.
- **N-5 Refusals are deliveries.** A refused or unresolved target is a delivery with `ok: false` and the fixed
  message "The target address is not permitted." (K7); nothing names the address, URL or reply.
- **N-6 Decision core is pure.** `decide(observation, state, settings, now) -> (new state, outbox kinds)` takes
  no I/O: transition Down/Up, resend after N Down beats, maintenance (no Down in maintenance, no Up after
  maintenance unless Down was sent), expiry thresholds keyed by `notAfter`.
