# WP-16 Tauri desktop shell (package plan)

Package orchestrator plan. Branch `claude/wp-16-tauri-shell`, from `phase-1` `e939dff` (WP-11 merged, R-042), worked in the reused WP-11 worktree (R-027). Task branches `wp/16-tauri-shell/<task>`.
Spec: CLI-001–004, REPO-003, LOG-007, Section 3 (platforms), Section 3.9 (updater: WP-04 stage B), Sections 12 and 13. WP-11 handoffs H-1, H-2, H-5, H-6.

## Decisions

- **D-1 Shell is OS work only (REPO-003).** `apps/desktop/src-tauri/` holds: the main window, the key-store commands, and the bundle configuration. No business rules, no GraphQL, no hub logic. The UI is `apps/client` unchanged on every platform (CLI-001); the shell serves its static build (`apps/client/build`) and, in development, the client dev server.
- **D-2 Key store (CLI-003, CLI-004, LOG-007).** The hub access token lives in the OS key store through the `keyring` crate: macOS Keychain, Linux Secret Service. One entry: service `ing.anima.desktop`, account `hub-access-token`. Three Tauri commands: `access_token_read` → `Option<String>`, `access_token_write(token)`, `access_token_clear`. Errors are a typed `thiserror` enum serialised as a code and a fixed message; neither the token nor the key-store error text that may echo it is logged or returned. Device credentials never reach the client (CLI-004; the hub keeps them).
- **D-3 Capabilities.** WP-16 grants its commands and the core window defaults to the `main` window in `capabilities/main.json`. WP-04 stage B adds `capabilities/desktop.json` for the updater; Tauri merges capability files.
- **D-4 Web view minimum (WP-11 H-1).** `bundle.macOS.minimumSystemVersion = "14.2"` (WKWebView 17.2, `linear()` springs). Linux builds need WebKitGTK 2.44+ (ubuntu 24.04 or later; WP-04's release job).
- **D-5 Security defaults.** A strict CSP in `tauri.conf.json`: `default-src 'self'`; `connect-src 'self' https: wss:` (the hub address is operator-set, CLI-002); no remote scripts; `withGlobalTauri` off; no shell, fs or http plugins.
- **D-6 Client wiring (H-2, H-5; proposal P-3, pending ruling).** `apps/client/src/lib/desktop/`: `token.ts` reads the key store through `invoke` (returns `null` outside Tauri; a key-store failure is the typed "token unreadable" path), `address.ts` keeps the hub address in local settings (CLI-002). The one `createHub` call in `routes/+layout.svelte` uses them.
- **D-7 Workspace (accepted as R-043: gates 1–3 must pass with no `apps/client/build`; `quality/README.md` notes the webkit2gtk-4.1 dev headers; report cold and warm gate cost).** `apps/desktop/src-tauri` joins the Cargo workspace so gates 1–3 cover it; `apps/desktop/package.json` holds `@tauri-apps/cli` and the `dev`/`build` scripts.
- **D-8 Scope.** Web-view sessions (WEB-004–010) are Phase 2 (spec 9) and not built here. The updater is WP-04 stage B.
