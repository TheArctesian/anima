# WP-18 — SSH terminal in the app (R-062)

Package branch: `claude/wp-18-ssh-terminal` from `phase-1`. Task branches: `wp/18-ssh-terminal/<task>`.

Design: [proposals/ssh-terminal.md](../proposals/ssh-terminal.md). Ruling: R-062 (K4 Section 8 opened;
RA-011 changed). Spec: SEC-006/007, R-032, R-034, RA-008, LOG-007, NET-002, OD-9, Sections 12 and 13.
Contracts: K1 (`startSession`, `tunnelPath`), K4 (Sections 1, 5, 6 apply; Section 8 is new).

## Scope

1. K4 Section 8 and the spec text for RA-011 (first task; the contract before code).
2. Hub: SSH session over `russh` with the accepted host key pinned, the R-032 target rule and the
   stored credential; PTY `xterm-256color`; `/terminal` WebSocket behind the ticket and
   NET-002; binary frames for bytes, closed JSON control set (`resize`, `ping`, `end`);
   backpressure, frame cap, 5 s / 15 s liveness; end reasons and events as K4 Section 5.
   `startSession` returns `tunnelPath` `/terminal` for SSH.
3. Client: the SSH session tab renders with `@xterm/xterm` (fit, WebGL with canvas fallback,
   search, web-links, unicode11); token theme; the shipped OpenDyslexicM font; OSC 52 off;
   links behind a confirm showing the URL; titles stripped of controls, 80 characters.
   The tab, toolbar, Keys menu and session list stay.
4. guacd stays for RDP/VNC; no SSH path goes to guacd after this package.

## Acceptance

- Gates 12/12; tests per K4 Section 7 with a fake SSH server (russh server in tests): full
  session, resize, each end reason, host-key mismatch, wrong credential, refused ticket.
- reviewer-security on the hub part; reviewer-interface on the tab in WebKit.
- The operator's fish prompt shows no OSC payloads in the real app.
