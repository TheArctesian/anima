## Decisions

- **P-1 Crate name.** Package `agent-core`, library `agent_core`, folder `crates/agent-core`, like
  `guac-protocol`. It depends on no other Anima crate (§13). Lints: `[lints] workspace = true`.
- **P-2 What moves in T1.** `metrics/parse.rs` becomes `agent-core/src/readings.rs`;
  `metrics/parse/{df,linux,macos}.rs` become `readings/{df,linux,macos}.rs`; `metrics/reading.rs`
  (the parser output types `Cpu`, `Memory`, `Load`, `Disk`, `Interface`, `Reading`) moves to
  `readings/` too, because the parsers return those types and `agent-core` cannot import the hub.
  Bodies are not rewritten; only paths, visibility needed across the crate edge, and doc links
  change. The hub face keeps `pub use agent_core::readings::{Cpu, Disk, Interface, Load, Memory,
  Reading}` so `metrics::Cpu` and the rest still resolve for every caller.
- **P-3 Parser tests move with the parsers.** `metrics/tests/{df,linux,macos}.rs` move to
  `agent-core/src/readings/tests/`. The captured device output (`metrics/tests/captures.rs`) has one
  copy, in `readings/captures.rs`, compiled only under `cfg(any(test, feature = "test-support"))`; the
  hub's dev-dependency turns on `test-support`, as the hub does for itself. Hub tests of rates and the
  collector keep using the captures from there.
- **P-4 GPU readings (T2).** `readings/gpu.rs` holds one output type per GPU: index, name, vendor,
  busy percent, VRAM (used and total bytes, only for a GPU with its own memory), temperature (°C),
  power (W), and for Apple the in-use system memory. Intel and Apple never have VRAM (MET-007). A field
  the source does not give, or gives as `[N/A]` / `[Not Supported]`, is `None`, never zero.
  - NVIDIA: the §6.6 `nvidia-smi` CSV form; memory is in MiB.
  - AMD: one pure reader per sysfs file (`gpu_busy_percent`, `mem_info_vram_used`,
    `mem_info_vram_total`) and a constructor for one card. The SSH framing that prints several cards'
    files is T3's (collector), so the agent and SSH share the per-file readers.
  - Intel: `intel_gpu_top -J`. Accept both the JSON-array form and the older comma-separated stream
    of objects; use the last complete sample. Busy is the highest engine `busy` value. Usage only.
  - Apple: `ioreg -r -d 1 -c IOAccelerator`: `Device Utilization %`, `In use system memory`, `model`
    and `gpu-core-count`. Usage only for display; no VRAM.
  - Like the existing readers: no panic, no failure on one bad line, the last line without a newline
    is dropped, labels pass `label`.
- **P-5 Gates and cargo runs.** `env -u DATABASE_URL BASE_REF=04ab9b61 bun run gates` in the task
  worktree. One `cargo test` or `cargo clippy` at a time in the package: a builder runs gates only when
  no other WP-51 builder is running cargo; reviewers read and do not run cargo (no security tag, so no
  mutations, R-066).
