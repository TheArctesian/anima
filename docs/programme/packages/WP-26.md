## What the hub serves today (59ab338)

- Served: `Device.rdp` (without `serverCertificate`), `vnc`, `macAddress`, `metricsSource`, `transfer`,
  `accessWarnings`; the web interface mutations (WP-30); `setRdpCredential`, `setVncCredential`,
  `acceptServerCertificate`, the remote `testConnection` (documents in `lib/sessions/api.ts`, WP-24).
- Not served (`@pending`): `Device.webInterfaces`, `webInterfaceSuggestions`, `readings`, `metrics`, `gpus`,
  `RdpSettings.serverCertificate`. A running document that selects one of these fails on the real hub.

## Decisions

- **D-1 Pending fields as unspread fragments.** A K1 `@pending` field is typed by a fragment that codegen
  reads but no running document spreads (`CardReadings`, `RdpServerCertificate`, `WebInterfaceFields`,
  `WebInterfaceSuggestionFields`). The read types are the generated fragment types; the field is optional on
  the device type until the hub serves it. Spreading the fragment is the one-line change when it lands.
- **D-2 Web interface documents live in `lib/web-interfaces/api.ts`.** The hub domain is `web_interfaces`;
  AGENTS.md asks for one GraphQL client per domain, codegen reads only `src/lib/*/api.ts`, and
  `lib/devices/api.ts` is already at its size limit. The folder is new and owned by no package.
- **D-3 One protocol-aware opener.** Card, table and header call `onConnect(device, protocol, button)`. The
  two route `connect` functions forward the protocol instead of the fixed `'SSH'` (the brief names these
  openers; three lines in `routes/devices/+page.svelte` and `routes/devices/[id]/+page.svelte`, flagged in
  the report). The Web button calls an optional `onOpenWeb(device, webInterface, button)`; it is hidden
  while no route gives it (WP-25 D-4 pattern). WP-31 owns the web tab.
- **D-4 Which buttons show.** Card and table: SSH when SSH is on with an accepted host key (Phase 1 rule),
  RDP when RDP is on, VNC when VNC is on (RA-030), Web when the device has a web interface (WEB-003).
  Header: SSH and RDP always (DEV-022: dashed with "+" when off, opening Settings at that section), VNC
  when on, Web when present, Edit last.
- **D-5 Metric bars before WP-28 and WP-33.** A bar row with the final geometry is always in the card:
  CPU, memory, disk, then VRAM only for a GPU with its own memory (MET-007, MET-008), `status-degraded`
  above 85 % (MET-004), values cross-faded (MOT-008). Without readings it shows an empty state in the
  same box ("No metrics" when the source is NONE, "Waiting for metrics" otherwise), so the card never
  changes size (MOT-007). WP-33's shared bar replaces the local one when it is on `phase-2` (P2-WAVE-003).
- **D-6 RA-020 badge.** A device with any `accessWarnings` shows a warning badge with text (not colour
  alone) on the card, the table row and the header; the tooltip lists each warning.
