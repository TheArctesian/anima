## Decisions

- **D-1 Files documents live in `sessions/files/api.ts`, wake in `sessions/wake/api.ts`, the live list in
  `sessions/live/api.ts`.** Codegen reads `src/lib/*/*/api.ts`; `sessions/web/api.ts` is the precedent. Each
  takes a `Hub` and returns `HubResult` values (CQ-045).
- **D-2 The files link mirrors the terminal link.** Same `tunnelUrl` rule (wss, ws only to loopback), the token
  only in the one constructor expression, subprotocol `anima-files`, `ping` after 5 s of client quiet (also
  during a download), lost after 15 s of hub silence. Close codes 1000, 1001, 1002, 1011 and 4002 map to fixed
  operator text. Hub messages are decoded as a closed set; anything else closes the link (fail closed).
- **D-3 Upload streaming.** The hub does not read the client while a create is in flight, so the client sends
  `upload`, then 64 KiB frames from `File.slice`, holding back while `bufferedAmount` is above a bound. On
  `refused` it stops sending and sends `cancel`. Progress is bytes the socket has taken (sent minus
  `bufferedAmount`), linear, no easing (MOT-009). `done` ends it.
- **D-4 Download.** `download {size}` then binary frames, summed until `size`, then `done`. Bytes over `size`
  close the link (1002 from our side). The bytes become a `Blob` saved through an `<a download>` with a name
  reduced to its last segment, no path separators or control characters. Progress = received / size.
- **D-5 One transfer at a time** in the client too: while a transfer runs, only `cancel` and `ping` go out.
- **D-6 Live list = `sessions(live: true)` then `sessionChanged`.** A pure reducer applies each change (start
  adds, end removes). Until WP-22 serves `sessionChanged`, the subscription errors; the list then keeps the
  query's answer and refreshes when the popover opens.
- **D-7 Nav item.** A button with the live count opens a popover (Menu and popover role: scale 0.96 to 1 and
  fade from the control with `spring-snappy`; exit fade and scale 0.98, `duration-fast`; reduced motion fade
  only). Each row: device, protocol, operator, client address, started; "Stop" calls `endSession`.
- **D-8 Wake.** `WakeButton` calls `wakeDevice` and shows "Wake packet sent through <relay>" or the fixed text
  of each WP-27 code. WP-26 places it (programme relays the props).
