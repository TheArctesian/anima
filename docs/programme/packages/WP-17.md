## Decisions

- **D-1 Paths of closed packages.** The 360 px fix and any motion fix touch files that WP-11, WP-12 and WP-13
  own. Those packages are closed, and the programme assigned the fixes to WP-17 in its brief. Each task names
  the exact files it changes; nothing else in those packages changes.
- **D-2 Audits are tasks.** The motion audit (MV-001–008), the log audit (criterion 12) and the code-quality
  audit (CQ-050) are run as tasks by reviewers that did not build the code. Their findings become fix tasks.
- **D-3 CQ-050 applies nothing.** CQ-050 says to apply only the items that the operator accepts. The operator
  is asleep, so the audit report is delivered in `docs/research/code-quality/` and no item is applied in this
  package. Items that are also motion or acceptance findings are fixed under those criteria instead.
- **D-4 Live checks.** The agents cannot drive the operator's desktop app or the VPS. A criterion that needs
  them is recorded as "operator to confirm" or "blocked", with the exact step.

### Test plans

- **T1.** Playwright in WebKit and Chromium at 360, 480, 768 and 1280 px: `document.documentElement.scrollWidth
  <= innerWidth` on `/devices` (grid, table, empty, 200 devices, a long name), `/devices/{id}`, `/settings`,
  `/sign-in`. A client unit test only where a pure function changes. No layout shift at the breakpoints (MOT-007).
- **T2.** The motion-audit procedure on synthetic data (K6 fixtures, a fake hub), MV-001 to MV-008: each Phase 1
  role in Section 5.7.3, interrupted (MV-003), per-frame `getBoundingClientRect` (MV-004), API delayed 400 ms
  (MV-005), view-transition support in WebKit (MV-006), reduced motion for each role (MOT-040, MOT-041).
  Report in `docs/research/motion/phase-1.md` with a ranked list (MV-007).
- **T3.** A hub integration test that parses the hub SDL and K1 and asserts that both have the same types and
  the same members with the same signatures. A difference is reported, not hidden; a K1 change is a contract
  request (CON-001).
- **T4.** Read every tracing, event, audit and client log call site; grep the code and the test output for
  secret-shaped values; run the existing LOG-007 tests with a mutation that removes a redaction.
