Device overview v2

The tab Overview of a device after the interface review of 2026-11-19 (R-224). The facts of the device (checks, uptime, how it is reached, the host key) are one strip, so the resources start higher. A card steps from the page by its surface and has no border. Beside them, a card lists each way in with its button, and a card gives what the device is. The storage table lists each drive of the machine, also one that is not mounted: it has its kind and its size, the words "Not mounted" where the mount point would be, and no used value and no read and write (operator, 2026-11-19: "i do also want unmounted drives to appear there"). A drive with several mounted partitions has one line for each mount under its name.
