# Phase 1 motion audit (Section 5.8, MV-001 to MV-008)

Audit of the Phase 1 client at `bb86ed8` (branch `wp/17-acceptance/motion-audit`, plan commit `04df738`). Reviewer: interface reviewer, WP-17 T2.
The reviewer did not build this code. No application code was changed. All data is synthetic (CON-003).

**Verdict for acceptance criterion 14 (Section 9.1): FAIL.** The first sentence holds: every Phase 1 role has a reduced-motion form
(MOT-040, MOT-041). The second sentence fails: 3 open "layout jump" findings (M-1, M-2, M-3) and 3 open "wrong motion" findings
(S-1, S-2, and C-1, which is sub-perceptual; see its note). Fix proposals are in section 5.
