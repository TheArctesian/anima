I was given the proposal `docs/proposals/agent-threads.md` (version 1), the documents it stands on (`contracts/work-route.md`, `contracts/daemon-push.md`, `docs/security-findings.md`, `docs/proposals/agent-layer.md`, `docs/proposals/bots.md`, `docs/proposals/agent-tools-as-extensions.md`, `docs/plans/cli-mcp-plan.md` Section 7, `docs/plans/extensions-plan.md`, `docs/research/agent-threads/t3-code-inventory.md`), the stage 1a code in the worktree `wt-threads-read` (commits `9b25f057` and `f0c1e008`), and eight attacker positions to take. I was not given the view of the author. I read the files and ran no program of the product. I changed no file other than this one. I read no secret file.

## 1. Findings

Severity: High = a way to run code on a machine, to read the content of threads from a place that must not have it, or to defeat an approval. Medium = a guard that is weaker than the text says, or a conflict with an approved rule. Low = a defect of small effect, or a wrong sentence.

## 3. Checked and found sound

- **No hub and no program in stage 1a.** `threads.rs`, `files.rs`, `shown.rs`, the MCP tool and the two shell commands open files only. No network call and no process start is in them.
- **The terminal.** The text form goes through `clean_file` when the output is a terminal; the table cleans each cell; `--json` to a terminal escapes DEL, the C1 controls and the direction characters. A piped output is raw, which is the rule of the command line for each command.
- **The ID of a thread.** `find` refuses an ID with `/` or `\` or fewer than 8 characters, never puts the ID in a path, and refuses when two files match.
- **A link as the last part of a path, a pipe, a device.** `named` uses the type of the entry without following it; `open_no_link` uses `O_NOFOLLOW`, `O_NONBLOCK`, `O_CLOEXEC` and then checks for a regular file. A linked project folder and a linked date folder are not entered.
- **A line cannot forge an entry.** The programs write tool output as a JSON string in one line; text inside it cannot start a new line of the file. A line that is not JSON changes nothing. (F24 is about the meaning of one field, not about this.)
- **The MCP tool returns no entry.** `anima_agents_threads` returns rows only; each string is cleaned and cut at 500 characters and the whole result at 60,000 bytes; unknown arguments are refused. THR-029 holds for MCP in the code.
- **The shell commands.** They are in the capability of the main web view only, they check the label again, they take no path, and their errors and their log line carry no path and no text (LOG-007).
- **The direction of the main choices.** Execution on the device as its user (THR-010); the device as the owner of the content (option B) rather than the hub; no Agent SDK and no login file (THR-020); no account method of `codex app-server` (THR-021); "not Working" for a file that changed (THR-013); no merge of drive code before the rulings (Section 1). THR-030 is the right binding of an answer to a request; it lacks only the proof of who answers.
- **The licence part.** THR-001 and THR-002 agree with the inventory (MIT, the Agent SDK under a different licence, the names and fonts).
