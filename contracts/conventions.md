# K7 — Conventions

Status: **frozen for Phase 1** (change only through a programme ruling, CON-001).

## IDs

- Every entity ID is a UUID v7 (time-ordered), generated by the hub.
- Rust: one newtype per entity, all in the leaf module `crates/hub/src/ids.rs` (see `hub-domains.md`), so that domains do not import each other only for an ID:
  `OperatorId`, `SiteId`, `DeviceId`, `CheckId`, `WindowId`, `SessionId`, `EventId`.
  Shape: `#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash, Serialize, Deserialize, sqlx::Type)] #[sqlx(transparent)] pub struct DeviceId(Uuid);`
- GraphQL: the `ID` scalar, as the UUID string. Parse with the newtype's `FromStr` at the API boundary.
- TypeScript: branded strings, e.g. `type DeviceId = string & { readonly __brand: 'DeviceId' }`.

## Time

- All stored and transmitted times are UTC. GraphQL scalar `DateTime` = RFC 3339 with `Z`.
- Durations in the API are integers with the unit in the field name: `intervalSeconds`, `responseTimeMs`.
- Core logic takes `now: DateTime<Utc>` as a parameter (CQ-021). Only `main.rs` and I/O edges read the clock, through `Clock` (see `hub-domains.md`).

## Errors

- Each hub domain has `pub enum Error` with `thiserror` (CQ-022). No `anyhow` in domains.
- Each domain error maps to one GraphQL error code in its `graphql.rs`:

  | `extensions.code` | Meaning |
  | --- | --- |
  | `UNAUTHENTICATED` | No valid token |
  | `FORBIDDEN` | Valid token, not permitted (or address not in a permitted network) |
  | `NOT_FOUND` | Entity does not exist |
  | `VALIDATION` | Input rejected; `extensions.fields` lists `{ field, message }` |
  | `CONFLICT` | Duplicate or stale state (e.g. host key mismatch) |
  | `UNAVAILABLE` | A dependency (database, gateway, device) is unreachable |
  | `INTERNAL` | Anything else; the message is generic, details go to the process log only (API-010) |

- Messages are plain sentences for the operator. They never contain SQL, file paths, secrets or stack traces.

## Logging (process log)

- `tracing` with JSON output (LOG-001). Standard fields: `request_id`, `operator_id`, `device_id`, `session_id`, `domain`.
- Spans at I/O boundaries only (CQ-026): GraphQL request, SQL call, probe, gateway connection, tunnel.
- Never log: passwords, private keys, passphrases, tokens, tunnel tokens, session content (LOG-007). Secret types implement neither `Debug` nor `Display` (see `hub-domains.md`).

## Configuration

Environment variables, read once in `main.rs` into a typed `Config` that is passed down:

| Variable | Meaning | Default |
| --- | --- | --- |
| `ANIMA_LISTEN` | Hub listen address (VPN or private interface, NET-003) | `127.0.0.1:8443` |
| `ANIMA_DATABASE_URL_FILE` | File containing the PostgreSQL URL (DB-002) | `/run/secrets/database_url` |
| `ANIMA_KEY_FILE` | File containing the credential encryption key (SEC-004) | `/run/secrets/anima_key` |
| `ANIMA_GUACD` | Gateway address | `guacd:4822` |
| `ANIMA_PERMITTED_NETWORKS` | Comma-separated CIDRs (NET-001) | VPN range + site subnets |
| `ANIMA_LOG` | Log level filter (LOG-003) | `info` |
| `ANIMA_TLS_CERT_FILE`, `ANIMA_TLS_KEY_FILE` | Hub TLS (SEC-001) | — (required outside tests) |

## Naming

- Follow CQ-030 (banned words) and the domain folder shape in spec Section 13.
- GraphQL: types `PascalCase`, fields `camelCase`, enums `SCREAMING_SNAKE_CASE`.
- SQL: one PostgreSQL schema per domain (see `database.md`), tables and columns `snake_case`.

## Tests

- A test that proves a requirement names the ID: Rust `fn chk_002_down_only_after_retries()`, TypeScript `it('CHK-002: down only after retries', …)`.
- Database tests use a throwaway database per test (`#[sqlx::test]`), never a shared one.
- Use the fixtures in `contracts/fixtures/` for synthetic data. Never real device data.
